# Многопоточный сервер задач

## Запуск

Нужен Python 3. Откройте терминал в папке задания и запустите сервер:

```console
python server.py
```

В другом терминале запустите клиент:

```console
python client.py
```

Для нескольких клиентов запустите `client.py` в нескольких терминалах.
Также можно запускать файлы через Run в PyCharm: сначала сервер, затем клиенты.
Адрес и порт заданы в `HOST` и `PORT`: `127.0.0.1:5555`.

## Команды

- `/add <текст>` — добавить задачу.
- `/list` — показать все задачи.
- `/done <номер>` — отметить задачу выполненной.
- `/quit` — завершить работу клиента.
- `/help` — как работают команды.

Номера начинаются с 1. Пустой текст, неправильные номера и неизвестные команды
возвращают сообщение об ошибке.

## Одновременная работа

Сервер принимает TCP-соединения и запускает `threading.Thread` для каждого
клиента. Все потоки работают с одним списком `tasks` на сервере.
Если один клиент добавил задачу, другой увидит её через `/list`.

## Синхронизация

В `server.py` используется `tasks_lock = threading.Lock()`.
Добавление, просмотр и отметка выполнения происходят внутри `with tasks_lock`,
чтобы потоки не обращались к списку одновременно во время изменений.
Проверка номера и отметка выполнения также выполняются под одним замком.
