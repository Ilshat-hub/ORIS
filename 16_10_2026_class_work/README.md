# Task Manager 2.0

Приложение на Python и PyQt6 для создания и отображения задач.

## Запуск



Установите зависимость:

```powershell
python -m pip install PyQt6
```

В терминале из папки проекта выполните:

```powershell
python main.py
```

## Использование

Введите название и описание задачи, выберите приоритет и дополнительные настройки. Нажмите «Добавить задачу».

Название обязательно: пустое значение или одни пробелы вызывают предупреждение. После добавления поля названия и описания очищаются, количество задач обновляется.

Список показывает название и приоритет. Описание и дополнительные настройки выводятся в консоль. Настройка уведомления собирается из формы, но системные уведомления не отправляются.

Счётчик символов названия обновляется при изменении текста.

Кнопка «Очистить список» запрашивает подтверждение. При отказе задачи сохраняются.

## Устройство

Интерфейс построен на QMainWindow с центральным QWidget. Используются вертикальный и горизонтальный layouts (Вертикальны в большинстве случаев, горизонтальный только при выборе степени сложности).

Кнопки подключены к методам окна через clicked.connect(). Изменения названия обрабатываются через textChanged. Предупреждения и подтверждения показаны через QMessageBox. Оформление задано единым блоком QSS.

Задачи хранятся только во время работы приложения. После закрытия список не сохраняется.
